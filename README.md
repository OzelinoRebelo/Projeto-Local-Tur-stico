# 🏖️ Beira-Mar de Fortaleza - Guia de Turismo

Página turística sobre a **Avenida Beira-Mar**, em Fortaleza, Ceará, desenvolvida com **HTML** e **CSS** a partir de um modelo do **Figma**, como projeto do meu curso de Full Stack.

A página apresenta a cidade e destaca atrações para quem quer conhecer a região, com foco em cultura, gastronomia e paisagem.
